# Release readiness

**Verdict: PUBLISHED AS BETA PRE-RELEASE, NOT ALL GATES MET.** `v4.1.0` (commit `348a433c`) was published on GitHub on 2026-11-10 as a pre-release at the owner's instruction, after green xUnit, green FlaUI regression and verified packages. The gates below that are PARTIAL remain open and must not be described as passed. Evidence: [QA_EVIDENCE.md](QA_EVIDENCE.md), [RELEASE_CANDIDATE_4.1.0.md](RELEASE_CANDIDATE_4.1.0.md).

Updated 2026-11-10.

**Post-release source work (NOT part of any published 4.1.0 archive):** `3ddfd0a`, `d6c1abc`, `e88b428`, `31c05b8`, `764fbbe`, `4d14fe0` hardened Corporate Lite packaging, added optional local ONNX reranker and explicit strict offline acceptance, updated the canonical plan and corrected public README status. These changes are not yet compiled or tested on Windows and were not signed or released. The earlier successful xUnit/FlaUI results are for the previous tested tree; they do not automatically validate later commits. The next native gate is a full model-containing Corporate offline ZIP with `-RequireReranker`, clean extracted package and `tests/corporate/measure-corporate-lite.ps1 -EnforceAcceptance`. Passing this smaller corpus test does not certify 30,000-page PDFs, 8 GB machines or enterprise readiness.

**Further work since the previous source note (not included in the 4.1.0 beta):** Corporate Lite now pins baseline ONNX embedding/reranker assets and checks the official Qwen3-4B GGUF hash, offers a local file-presence/recheck surface, and has source tests plus an extracted-package smoke that must load the real ONNX engines. Strict Corporate acceptance requires the live engine loads, synthetic document retrieval, source-grounded Chat, and no observed non-loopback connections. A corrupted duplicate script tail was corrected before this checkpoint (single-builder guard added). **No current-source Windows build, xUnit, FlaUI, native execution, clean 8–16 GB test, benchmark or new signed package was run in this remote session.** See the latest `HANDOFF.md` and `PARUX_EXECUTION_PLAN.md`. The 4.1.0 release remains unchanged.

**Additional 10 November source tranche, not part of v4.1.0 beta:** Gaming's first-visit Steam/Epic/GOG detection is now opt-in with persistent skip and per-provider failure isolation; it refuses scans during active Gaming. A new FlaUI test for skip/persistence was authored but **not executed**. Corporate `ServerState.Publish` now uses fail-closed current-user ACL protection and refuses reparse points for portable Core tokens, with a source contract. These updates have **not** passed Windows build, real-game startup, low-spec Corporate, GPU/FPS, permissions/security or FlaUI regression gates. The published pre-release remains unchanged. See newest `HANDOFF.md` and `PARUX_EXECUTION_PLAN.md`.

**Further post-beta source work — portable distribution, NOT yet released:** The Standard ZIP builder now stages a hash-locked Qwen3-4B starter, CPU and Vulkan native inference engines, ONNX embedding and reranker, and .NET/WinUI self-contained Desktop/Core, with full-archive SHA256 verification and exact portable data-root markers. The direct EXE resolves colocated data even after relocation and a preexisting host install cannot supply missing models; Standard CPU fallback is source-implemented. The Corporate CPU build shell now uses a distinct stage and internal ZIP name, preventing it from overwriting the Standard Portable package; `-SkipPublish` rejects mismatched source/edition. Newly authored unit/source-contract tests and smoke code have not been run. **Current source may still fail Windows compile, PowerShell 5.1 parsing, native dependency loading or live AI/RAG tests.** No clean target PC/USB and no independent Windows QA; no new signatures/releases. Advanced media/training, game clients and Windows driver dependencies remain optional, and Corporate permission protection may reject FAT/exFAT USB volumes.
