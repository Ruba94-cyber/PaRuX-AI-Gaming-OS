# Reviewed inventory of every process launch under src/PaRuX.App (the WPF shell and its agent tools).
# Enforced by GamingHardOffProcessLaunchInventoryTests.EveryAppProcessLaunchIsClassified: a new launch site or a changed count fails the test.
# This inventory is deliberately simpler than the Server one: it records the DECISION per file, it does not prove a gate.
#
# Format:  relative path | launch-site count | class | decision
# Classes:
#   GAMING-FEATURE  part of the game integration itself.
#   USER-ACTION     started by an explicit user click or by app start, not an AI workload (opening a document, starting the PaRuX server host,
#                   launching or testing an external client the user chose).
#   AI-CHILD        a CPU tool child run on behalf of a local coding / analysis / computer-use agent. No model runs in it; the agent that
#                   starts it is itself refused while Gaming Mode is active (see the decision text for where that refusal lives).
#   NOT-AI          a bounded OS or telemetry probe.
#
